Clean Wash Laundry (Kotlin + Laravel)

Usaha laundry yang menerima pesanan lewat chat kewalahan saat pelanggan bertambah: pesanan tercecer, status cucian ditanyakan berulang, dan rekap harian dihitung manual. Aplikasi ini memindahkan seluruh alur ke aplikasi Android native Kotlin dengan backend Laravel.

Kotlin Laravel WhatsApp

Masalah yang diselesaikan

Pemilik laundry harus membalas pertanyaan "cucian saya sudah selesai belum?" puluhan kali sehari. Pesanan yang masuk lewat beberapa nomor berbeda mudah terlewat, dan tidak ada catatan rapi untuk menghitung pendapatan.

Aplikasi Android native dan API terpisah

Sisi pelanggan dibangun native dengan Kotlin agar ringan dan responsif di perangkat kelas menengah ke bawah. Seluruh data dilayani backend Laravel melalui REST API, sehingga panel admin berbasis web dan aplikasi mobile memakai satu sumber data yang sama.

Pelacakan status dan notifikasi otomatis

Setiap pesanan melewati tahap yang jelas mulai dari penjemputan, pencucian, hingga siap diambil. Perubahan status memicu notifikasi WhatsApp otomatis yang telah disiapkan untuk layanan gateway seperti Fonnte, sehingga pelanggan tidak perlu bertanya lagi.

Fitur utama yang dibangun

  • Aplikasi Kotlin Android untuk order & tracking status.
  • Backend Laravel API untuk alur order/pembayaran.
  • Notifikasi WhatsApp (siap Fonnte).

Pertanyaan seputar proyek ini

Kenapa memakai Kotlin native dan bukan aplikasi hybrid?
Kotlin native memberi performa dan akses perangkat yang lebih baik pada ponsel spesifikasi rendah, yang banyak dipakai pelanggan layanan harian seperti laundry. Ukuran aplikasinya juga lebih ringan.
Apakah notifikasi WhatsApp dikenakan biaya terpisah?
Ya, biaya mengikuti penyedia gateway WhatsApp yang dipilih. Aplikasinya sendiri sudah disiapkan agar tinggal dihubungkan dengan kredensial penyedia tersebut.
